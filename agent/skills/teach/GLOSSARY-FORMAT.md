# GLOSSARY.md format

Every teaching workspace must contain a `GLOSSARY.md` file that defines shared terminology. All explainers, exercises, and learning records must use terms as defined here.

## Template

```markdown
# Glossary

| Term | Definition | Source |
|------|-----------|--------|
| <term> | <concise 1–2 sentence definition> | <URL or resource reference> |
```

## Rules

- Add terms only after the user has demonstrated understanding — not speculatively
- Definitions must be concise: 1–2 sentences maximum
- Every definition must cite its source (URL, book title + page, paper, etc.)
- Never redefine a term already in the glossary — use it consistently
- Terms accumulate across sessions; never remove a term (only amend if the original was wrong)
- Sort alphabetically
- If the user learns in a non-English language, define terms in that language — but keep the format and `Term` / `Definition` / `Source` headers in English for tooling compatibility
